# 阶段四权重说明

本目录随仓库上传的三个 `.pt` 文件来自 `train_ppo.py --quick`，用途是验证：

- Actor/Critic/Estimator 权重可以保存和加载；
- 评估脚本与 Pygame 演示能正常读取 checkpoint；
- 换电脑后能够快速检查阶段四运行链路。

这些权重只训练了极少迭代，不具备论文中的墙面爬行和速度跟踪能力，不能作为正式实验结果。
正式复现需要运行完整 35000 次迭代，并用 `eval_rl.py` 重新统计指标。

`.gitignore` 仍会忽略后续产生的 `.pt` 文件，避免正式训练生成的大量权重不断进入 Git 历史。
