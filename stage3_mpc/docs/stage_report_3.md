# 阶段报告（阶段3：论文1 MPC 控制器复现）

## 2. 架构（对照论文1 Fig.5）

1. **步态调度器**（control/gait.py）：对角小跑，周期 0.5s，占空比 0.45，
   EPM 命令提前 5ms 开启（复现论文1 的磁铁提前量）。
2. **SRB-MPC**（control/mpc.py）：单刚体线性动力学
   m·p̈ = Σu + m·g，I·φ̈ = Σ(r×u)，H=10、dt=0.02s 时域，
   凝聚成 80 维 QP：
   - 滑移锥 |u_t| ≤ μ·(f_mag + u_n)，μ=min(μ_s, μ_t)=0.185（阶段1 结论）
   - 吸附/踝关节盒 u_n ∈ [−697.1, +250] N（f_n_max 为踝力矩上限）
   - 关节力矩 |J_wᵀu| ≤ τ_max=30 N·m（补执行器极限）
   - 代价 Q=diag(0,3000,100,200,10,5)、R=1e-6（min-norm 正则）、
     Rd=1e-4（力变化率平滑，承担真正正则——MᵀQM 秩 ≤6H<8H，
     零空间方向全靠 Rd 的 DᵀD 覆盖，条件数 ~6）
   - 参考调速器：z_target = z_nom + k_b·∫e（k_b=2.0，±0.05 限幅）、
     vx_target = v_cmd + k_bv·∫e（k_bv=1.0，±0.3 限幅）——恒值参考下
     QP 会选"推迟到预测尾部再推"的等价计划、步0 命令恒为 mg，
     闭环钉在偏低不动点；积分偏置强迫步0 就推
3. **力实现（关键机制）**：支撑腿力矩前馈 τ_ff = −J_wᵀ·u，位置通道
   "原地钉扎"（目标 = 本步起点足端位置，保持受力下沉变形，绝不拉回
   锚点）。无质量腿的静力平衡 F_env = −J⁻ᵀτ 把期望 GRF 直接写进接触力，
   **实现率 97.5%**（残余 2.5% 由 MPC 反馈消除）。对照教训：把 u/k_t
   写进锚点弹簧变形的旧方案，关节 PD 等效刚度 kp/|JJᵀ|≈5.3kN/m 使
   足端在切向力下沉 F·|JJᵀ|/kp，实现率只有 2.6%——躯干被锚点弹簧
   "拖着"不动。
4. **摆动腿**：三次 Bézier smoothstep + 半余弦抬脚（lift=0.04m），
   落足点按 Raibert 法则 p_land = p_hip + T_st·v/2 + k_v(v−v_des)
   在离地时刻计算。

## 3. 调试历程（墙面步态保持的五处修复）

墙面步态保持（test 场景3 的核心）曾从第一步就失败（Fz=−83、vz=−0.12、
支撑腿 gap 只有 −0.5mm 而非静平衡 −0.7mm）。逐子步探针逐层定位：

1. **腿对耦合改差分误差绑定**（根因 #1）：腿对耦合弹簧原本 k=1e4 绑定
   绝对姿态，而小跑步态耦合对 (0,2)/(1,3) 相位恒差 0.5——一条钉扎一条
   摆动时，摆动腿被锁在钉扎腿姿态上（耦合刚度是关节 PD 的 16 倍，
   实测摆动腿被施加 ±26-36 N·m 而命令只有 ±12）。改为绑定
   (q_b−q_a)−(q_des_b−q_des_a) 差分误差、k 降到 600（与 PD 同量级）。
   验证：摆动腿 gap −0.70→+2.40mm 精确跟踪目标，钉扎漂移仅 0.04mm。
2. **接触阻尼限幅 + 磁力一阶滞后**：磁铁提前 5ms 开启，无质量足端被
   697N 猛拉撞墙（v_n 1-2m/s），阻尼 d_n·v_n 产生 1500-3000N 冲击脉冲。
   damp_cap=150N 限幅 + 磁力一阶滞后 τ=5ms（复位时 f_mag 给满避免复位踢）。
3. **法向刚度加硬 k_n 1e6→5e6**：无质量足端模型的落地弹簧储能
   0.5·k_n·pen² 全部倒进躯干（真实机器人有足端质量+弹性体吸收），
   5e6 使穿透 0.72→0.14mm、能量 5 倍小；ω=√(4k_n/m)≈1581 rad/s
   在 0.2ms 子步的显式积分稳定域内。
4. **tau_peak=150**（实测无效但保留）：猜测落地瞬时接触负载
   Jᵀ·(f_spring−f_mag) 瞬时可达 100-250 N·m 致关节折叠。实测限幅
   前后输出逐位相同——关节限幅从来不是问题。保留因"30N·m 只是
   持续值、150 为峰值"有理据且无害。
5. **落地钉扎压到壁面（决定性修复）**：摆动 smoothstep 末端渐近趋近
   壁面，追踪滞后 ~0.1mm 使落地钉扎悬空；无弹簧约束时腿对耦合
   可把悬空足拖高 4mm 且永不落地（逃逸正反馈，实测落地腿 gap 反升
   +4.4mm）。落地事件把钉扎点 z 压到壁面。**验证：墙面步态保持
   完整 2.4s 通过**（z 0.137-0.154 周期振荡、φ≤−0.033、vx≈0 无滑移）。

残余毛刺（可接受）：落地瞬时 Fz 尖峰 +747..+792N（弹簧建立快于磁力
斜坡），不破坏稳定。

## 4. 求解器性能（96ms → 3ms）

- 瓶颈定位：polish 活动集精修的 KKT 求解占 96.7ms/步。根因是
  **OpenBLAS 多线程对小矩阵的病态开销**：120×120 稠密 solve 在
  24 线程下 210ms、单线程 0.22ms（慢 1000 倍），80×80 反而 0.25ms。
- 修复：venv site-packages 加 `sitecustomize.py` 设置
  `OPENBLAS_NUM_THREADS=1`（必须解释器启动时设置，numpy 导入后
  再设环境变量无效）。本项目矩阵全部 ≤300 维，单线程恒更快。
- 结果：coneqp 6.1→1.9ms、polish 96.7→1.1ms，单步求解 ~3-4ms
  （max 8.2ms，预算 20ms）。test_mpc 总耗时 145.6s→59s。
- polish 保留的理由：coneqp 冷启动（无热启动初值）在近零曲率方向
  提前判停、解漂移严重（实测稳态冷解 Fz=162.6 vs 真最优 78.4），
  polish 两步拉回。闭环热启动路径下 polish 恒为空转，但单线程下
  代价已降至 1.1ms，保留作安全网。

## 5. 已知局限

- 平地全支撑保持存在慢收敛瞬态：下探到 z=0.1406（k≈35-40）后单调
  恢复到 0.1485（80 步内），原因是钉扎位置通道把下沉位型"重新锚定"、
  恢复只能靠 MPC 力反馈+积分调速器；墙面保持（法向无重力分量）
  无此现象，稳如磐石。
- 无质量足端模型的落地/离地瞬态与真实机器人有本质差异（见第3节
  修复 3/4 的说明），已通过限幅+滞后+刚度加硬缓解。
