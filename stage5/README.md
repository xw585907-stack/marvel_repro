# 阶段五：对比与消融实验

目标：在同一二维物理环境与评估协议下，完成 PPO 训练因素消融，以及阶段三 MPC 与阶段四 RL 的吸附失败对比。原论文的 Table II 与 Fig. 5 是实验设计参考；本项目采用二维解析步态加 PPO 残差，结果须标明工程适配差异。

第一组先运行 **Full（完整方法）**：使用当前阶段四 PPO、三阶段课程、概率吸附和真实几何/气隙磁吸模型，从随机初始化开始训练 35,000 次，seed=0，64 个并行环境，每次 rollout 32 步。后续消融组需保持网络、奖励、训练预算和步态先验一致，每次只移除一个因素；现有阶段四最优权重仅作为历史参考，不直接替代这组公平对照。

训练过程和检查点保存在 `checkpoints/full_seed0/`。该目录默认不纳入 Git；验收后只选择报告所需的最终权重与结果上传。正式结果和评估协议将在本目录补充。
